# TVBox 自托管源(yinshiyuan 抢救版)

原 `wanganni/yinshiyuan` 仓库及账号已从 GitHub 删除,本仓库是本地存档的整理版:
所有指向原仓库的死链已改为**相对路径**,缺失文件已从社区镜像(cluntop/tvbox、hebijunge/tvbox-config 等)尽力补回。

## 订阅地址(TVBox app「配置地址」里填)

- 普通版:`https://raw.githubusercontent.com/keepongoin/tvbox/main/tvbox.json`
- 18+:`https://raw.githubusercontent.com/keepongoin/tvbox/main/tv18.json`
- 18+ 备用入口:`https://raw.githubusercontent.com/keepongoin/tvbox/main/tvbox18.json`
- 综合:`https://raw.githubusercontent.com/keepongoin/tvbox/main/tvboxzonghe.json`

## 说明

- jar、logo、子配置全部走仓库内相对路径,不依赖任何第三方仓库存活。
- `tv/py/` 的 drpy python 爬虫大部分已随原仓库遗失,对应站点已从源里剔除;
  `tv/xbpq/`、`tv/XYQHiker/` 等按文件名从社区镜像补回了约 80 个。
- 仅技术交流用途。
